# PI / DeltaV Historian Analyzer

A standalone Python toolkit for analyzing process historian tag data of
the kind exported from **OSIsoft PI** or an **Emerson DeltaV PCS**
historian, focused on downstream biopharma skids: ultrafiltration (UF),
column chromatography, and their CIP/SIP cycles.

No live PI or DeltaV connection is required — the tool reads a CSV
export in the same column shape a PI Web API call or historian SQL
query would return. Swapping the CSV loader for a live client is a
one-function change; the analysis logic (spec checking, CIP/SIP hold
verification, batch-to-batch drift) does not change.

All sample data is synthetic, generated by `scripts/generate_sample_data.py`.

## What it does

- **Spec-limit excursion detection** — flags every reading outside its
  tag's low/high limits and summarizes excursion counts per batch,
  equipment, and tag (`historian_analyzer/excursions.py`)
- **CIP/SIP hold-time verification** — checks that a clean-in-place or
  steam-in-place cycle actually held its required temperature for the
  minimum continuous duration, not just touched the setpoint once
  (`verify_cip_sip_hold`)
- **Batch-to-batch trending** — rolling mean of a tag's per-batch
  average, to catch slow drift (e.g. a UF membrane's permeate flux
  declining over successive batches) that a single-batch spec check
  would miss (`historian_analyzer/trends.py`)
- **Chart generation** — matplotlib PNGs for every equipment/tag
  combination, plus drift charts (`historian_analyzer/plotting.py`)
- A **CLI** that ties it all together (`historian_analyzer/cli.py`)

## Quick start

```bash
git clone https://github.com/<your-username>/pi-deltav-historian-analyzer.git
cd pi-deltav-historian-analyzer
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python scripts/generate_sample_data.py
python -m historian_analyzer.cli --input data/sample_historian_export.csv --output-dir output

pytest tests/ -v
```

`output/` will contain `excursion_summary.csv`, per-tag CIP/SIP
hold-verification CSVs, `batch_tag_summary.csv`, and a `charts/`
directory of PNGs.

## The included demo scenario

The generated sample data deliberately includes two findings for the
tool to catch, so you can see it work on the first run:

1. **UF-SKID-01 permeate flux drifts down across 6 sequential batches**
   (simulating membrane fouling) — visible in the drift chart.
2. **One CIP cycle (BATCH-2003) fails its 20-minute hold-time
   requirement** — the temperature touches the setpoint but doesn't
   hold, which `verify_cip_sip_hold()` catches even though a naive
   "did it ever reach 60C" check would pass it.
3. **One chromatography batch has a UV280 excursion** above the
   2.5 AU high limit.

## Point this at your own data

Use any CSV with columns `equipment_id, batch_id, tag_name, value, uom,
timestamp` (ISO 8601 timestamps). Edit `historian_analyzer/specs.py` to
match your own tags and limits, or load an alternate spec table with
`load_specs_from_json()`.

## Why this project

Built to demonstrate practical historian data analysis for downstream
biopharma unit operations — reading PI/DeltaV-style tag exports,
verifying CIP/SIP cycles against spec, and spotting equipment drift
trends — using only free, local tooling (pandas, matplotlib).
